How to use
1
Download SteamCM.exe and place it in any folder you like.
2
Run the executable. Steam must be installed — the path is detected automatically.
3
Use the arrow keys to navigate and Enter to confirm.
4
Search for a game by name or App ID, then install its manifests in one click.
5
Relaunch Steam from the menu to apply changes with a fresh download cache.
